- Change (commit 9b3abcc, off by default; cuda_rasterizer/rasterizer_impl.cu, switch value GS_OPT_RASTER=31):
  duplicateWithKeysCoop<16>. Same launch geometry (one thread per Gaussian). Each thread first evaluates the tiles of
  its own Gaussian when its rectangle has at most 16 tiles (upstream's loops and arithmetic); then every warp takes,
  one after the other, each of its lanes whose Gaussian has more than 16 tiles and evaluates its tiles with all 32
  lanes (32 tiles per step, compacted with __ballot_sync / __popc so that a Gaussian's kept tiles land in the
  same order). The two reciprocals of the tile test (PATCH_WIDTH^2 * co.x, ... * co.z) depend on the Gaussian
  only and are computed once per Gaussian instead of once per tile: the same operation on the same value. Every slot
  gets the same key and value as upstream's kernel, so the sort input and everything after it are unchanged.
