3.9 hRound 8 (dev worktree /tmp/r3-dev2, branch dev-round8; in progress): decode replay with one step of lookahead (switch R3OPT_DECODE_PIPELINE, needs R3OPT_DECODE_GRAPH)
- Finding (r4 profile, decode window): each token costs one cudaGraphLaunch of ~2.4 ms CPU time during which the GPU is idle,
  then a ~8.4 ms replay: ~11.2 ms per token, the replay is ~75% of it.
- Design: the replay of the next step (same active set, device-side state: current tokens and positions updated before
  the launch) is queued before the host reads this step's tokens. If no sequence finishes, it is the next step. If one
  does, the lookahead is rolled back (cache lengths, positions, current tokens of finished sequences, generator state
  restored to the state after this step's replay) and the step is replayed for the new active set.
- Tiny-model test (/tmp/analysis/unit/test_decode_pipe.py): 128 runs default and 128 deterministic, all identical
  (tokens, probabilities, generator state, live cache entries, lengths, positions, current tokens); overflow raises the
  same error (/tmp/analysis/unit/overflow_pipe.py).
