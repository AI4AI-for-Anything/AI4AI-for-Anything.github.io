### Change implemented this round (train side, behind switches, default off)

1. OPD_SKIP_KL0_REF_PASS=1 — skip the separate ref-model log-prob forward when kl_coef == 0 and
   kl_loss_coef == 0 (its only consumer is 0 × kl). Also skips the pointless _switch_model("actor")
   re-restore when no model was switched. Loss skips the KL term when ref_log_probs is absent and the
   coef is 0; train/kl_loss metric then not reported (judge reads only train/loss, grad_norm,
   train_rollout_logprob_abs_diff — verified in bench.py:1262-1267).
2. OPD_FUSED_ADVANTAGES=1 — skip the separate actor log-prob forward and apply the OPD reverse-KL
   advantage term inside the train loss from the train pass's own (detached) log-probs; base GRPO
   advantages still come from compute_advantages_and_returns. Gated on: 1 train step/rollout,
   policy_loss, kl_coef 0, kl_loss_coef 0 (or no use_kl_loss), no rollout-logprobs/mismatch/critic/
   normalization/score-centering/tis/opsm/routing-replay/rollout-entropy, grpo estimator, use_opd with
   sglang teacher, teacher_log_probs present. The loss's existing old_log_probs fallback
   ([lp.detach() for lp in log_probs]) then reproduces the reference's old_log_probs exactly.
3. OPD_FUSED_ADVANTAGES_VERIFY=1 (evidence mode, not for submission) — runs the reference path AND
   captures the train pass's log-probs, logging max|train_lp − separate_lp| and the count of
   bitwise-equal samples per rollout.
