### Baseline Profile Highlights (/tmp/r1)
- Train (train_overall_rank_0, peak CUDA alloc 37.96 GiB / 141 GiB):
  - ref_log_probs: 12.60s unprofiled even though --kl-coef 0 --kl-loss-coef 0.00!
  - --entropy-coef 0.00 still runs with_entropy=True (einsum + TP all-reduce) across all 64 microbatches.
  - ReloadableProcessGroup _wrap_low_level_call calls cudaMemGetInfo + psutil.virtual_memory() ~10,105 times (3.07s!).
  - HybridDeviceOptimizer.step(): ~9.84s (188 sequential per-tensor AdamW calls on CPU while GPUs sit idle, likely with low thread count + 188 per-tensor event syncs).
  - Full activation recompute (recompute_granularity full, num_layers 1): CheckpointFunctionBackward is ~60-70% of forward+backward span while >100 GiB HBM sits unused!
  - score_centering + get_log_probs_and_entropy: two full vocab FP32 softmaxes (first over ALL T tokens including prompt/pad, then again per-sample on top-128).
  - 24x Qwen3_5GatedDeltaNet: replicated across TP=2 and CP=2 (all-gathered every layer).
  - sleep() (4.10s) + wake_up() (1.49s incl. redundant _switch_model("actor")).
- Rollout (110.74s, GPU busy only 32.2%):
  - Sampler.forward:321 .any().item() sync (761.63ms / 200 steps).
  - logprob_processor / managers/utils per-row top-128 D2H .tolist().
  - tokenizer_manager building ~1M Python (float, int, None) tuples.
  - try_small_copy, CUDA finalize_fused_in_proj, decode softmax+topk fusion, decode CPU scheduling overhead.

### Rollout Round R1 (Committed sglang 82aa006, verified PASS N1, Rollout 48.185s vs 110.739s ref -> 2.301x rollout, 1.9628x proj step)
- Changes (sglang/):
  - SGLANG_OPT_NO_LOGPROB_SYNC=1 (sampler.py, sampling_batch_info.py): cache temperatures_cpu, is_all_temperature_one, return_top_p_token_ids_cpu, and return_top_p_log_probs_cpu on host across batch init / filter / merge, avoiding .any().item() GPU->CPU stall and div_(1.0).
  - SGLANG_OPT_BATCHED_TOP_LOGPROBS_D2H=1 (logprob_processor.py, managers/utils.py, batch_result_processor.py): return dense [B, K] fp32 values & int32 indices from get_top_logprobs_raw for uniform decode top-k, transferring via batched async_d2h instead of per-row slices.
  - SGLANG_OPT_FLAT_OUTPUT_TOP_LOGPROBS=1 & SGLANG_OPT_SKIP_REDUNDANT_TOP_LOGPROBS=1 (batch_result_processor.py, io_struct.py, multi_tokenizer_mixin.py, detokenizer_manager.py, output_streamer.py, tokenizer_manager.py): stream flat numpy (val, idx) chunks per sequence instead of allocating millions of Python lists/tuples (output_top_logprobs_val_chunks/idx_chunks).
  - SGLANG_FORCE_STREAM_INTERVAL=100000: disable frequent intermediate token streaming IPC during forced-length decode.
  - (SGLANG_OPT_USE_GUMBEL_SAMPLE=True default in sampler.py avoids torch.multinomial host sync/validation).
- Combined Projected Speedup (R1 + T3): 1.9628x (rollout 48.185s, train 38.669s).

### Rollout Round R2 (Committed slime a89e5206, sglang ce1f9cc, verified PASS N1, Rollout 42.875s vs 110.739s ref -> 2.5828x rollout, 2.0815x proj step)

  - SLIME_OPT_ROUTER_BALANCE=1 (slime/ray/{rollout.py,serving.py}): launch router with policy='round_robin' on a shallow copy of args when router_policy is unset or cache_aware, eliminating the 36/28 request imbalance between engines so both stay at #running-req=32.
  - SGLANG_OPT_DIRECT_LOGIT_LOGPROBS=1 + SGLANG_OPT_BF16_LOGITS_BUFFER=1 (fused_sampler_topk.py, sampler.py, logits_processor.py, graph_shared_output.py, base_runner.py, model_runner.py): two-stage Triton online logsumexp + Gumbel-max T=1 sampling + FlashInfer radix_topk(128) normalization directly from BF16 logits without materializing [M, V] fp32 softmax/log_softmax/argmax/gather tensors, keeping next_token_logits_buffer in BF16 (with safe fp32 fallback cast for custom/greedy/penalty paths and TP seed broadcast in prewarm_sampling).
  - SGLANG_OPT_CUDA_FUSED_IN_PROJ=1 (models/qwen3_5.py): enable finalize_fused_in_proj() on CUDA for all 24 GDN layers inside load_weights (TMS model_weights region), fusing in_proj_qkvz and in_proj_ba into one BF16 GEMM (M <= 1024).
  - SGLANG_OPT_AG_MIN_BLOCKS=32 (triton_symm_mem_ag.py): launch symmetric-memory all-gather with 32 blocks instead of 4.
  - SGLANG_OPT_GDN_DECODE_BV=8, SGLANG_OPT_GDN_DECODE_WARPS=2, SGLANG_OPT_GDN_DECODE_STAGES=2 (kernels/ops/attention/fla/fused_recurrent.py): increase occupancy of packed GDN decode recurrence.
